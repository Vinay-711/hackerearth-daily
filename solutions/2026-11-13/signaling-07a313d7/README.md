## Approach

The problem is solved by iterating through the string once, maintaining a counter for consecutive '1's. Whenever a '1' is encountered, the counter is incremented and compared against the maximum found so far. If a '0' is encountered, the counter is reset. The time complexity is O(N) and space complexity is O(1) beyond the input storage.
