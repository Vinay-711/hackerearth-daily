## Approach

A number is divisible by 10 if and only if its last digit is 0. The problem asks to form a number by concatenating the last digits of all input integers and check if that resulting number is divisible by 10. This is equivalent to checking if the last digit of the last number in the sequence is 0. The time complexity is O(N) to read the input, and space complexity is O(1).
