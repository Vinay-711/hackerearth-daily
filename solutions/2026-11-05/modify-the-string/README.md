## Approach

The solution iterates through each character of the input string. For each character, it checks if it is uppercase using Character.isUpperCase() and converts it to lowercase using Character.toLowerCase(), or vice versa. This approach has O(N) time complexity and O(N) space complexity where N is the length of the string.
