## Approach

The problem asks to calculate the minimum cost of balloons for two scenarios: (1) Green for problem 1, Purple for problem 2, and (2) Purple for problem 1, Green for problem 2. We count the total number of participants who solved problem 1 and problem 2, then compute the cost for both scenarios and return the minimum. Time complexity is O(T * N) and space complexity is O(1).
