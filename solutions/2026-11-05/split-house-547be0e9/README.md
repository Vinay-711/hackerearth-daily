## Approach

The problem asks to place fences (B) in empty spaces (.) such that no two houses (H) are adjacent. If two houses are adjacent, it is impossible to prevent them from reaching each other, so we output NO. Otherwise, we can fill all empty spaces with fences to maximize the number of fences, which satisfies the condition that each person can only reach their own house. Time complexity is O(N) and space complexity is O(N).
