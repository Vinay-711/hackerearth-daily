## Approach

The problem requires counting the number of distinct elements in an array and comparing it to X. Using a HashSet is the most efficient way to find distinct elements, providing O(N) time complexity per test case and O(N) space complexity. We use BufferedReader for fast I/O to handle the constraints efficiently.
