## Approach

The problem requires sorting fans based on their quotient in descending order, and lexicographically by name in ascending order for ties. I used a custom class 'Fan' implementing Comparable to define this logic. The time complexity is O(N log N) due to sorting, and space complexity is O(N) to store the fan data.
