## Approach

The problem asks for the number of steps to slice all fruits, where each step involves slicing all fruits of a specific weight. This is equivalent to counting the number of unique weights present in the array. Using a HashSet to store the weights allows us to find the number of unique elements in O(N) time complexity and O(N) space complexity.
